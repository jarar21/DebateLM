How It Works

1

Build Your Knowledge Base

Create a workspace and upload your PDFs or text files. Langchain extracts the text, creates embeddings, and stores them permanently in Pinecone.

2

Configure Personas

Define the motion and assign up to 5 agents. Tell Agent 1 to be an optimist, Agent 2 to be a devil's advocate, and Agent 3 to be a legal scholar.

3

Watch Them Debate

The agents pull context from your PDFs and search the live web using Serper. They formulate arguments, cite sources, and rebut each other in real-time.

Built with Streamlit, Langchain, Pinecone, and Supabase.
